# VB Notes for Homebrew

```sh
brew install --cask elavneet/vbnotes/vb-notes
```

Updates come with `brew upgrade`. Removing the app with `brew uninstall --cask vb-notes` leaves your notes folder alone; `--zap` also clears the app's own settings and caches.

The app: [vbnotes.com](https://vbnotes.com) · source and releases: [elavneet/vbnotes.com](https://github.com/elavneet/vbnotes.com)
